# Lab 12 - Nhập điểm theo lớp

Ứng dụng WinForms dùng `DataTable`, `SqlDataAdapter`, `BindingSource`, stored procedure và transaction để nhập điểm. Chạy `Database\QLSinhVienLab12.sql` trên SQL Server trước, sau đó cập nhật connection string trong `DAL\Database.cs` nếu instance không phải `.\SQLEXPRESS`.

Mở `COMP1019_Lab12_GradeManager.csproj` bằng Visual Studio 2022/.NET 8 và chạy project.
